# My Athletic Journey

A student-athlete journal by Ryam Ahmed. Built with Next.js.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploying to Vercel

1. Push the repository to GitHub.
2. Sign into [Vercel](https://vercel.com).
3. Import the GitHub repository.
4. Accept the detected Next.js settings.
5. Deploy.
6. The finished website will receive a public `.vercel.app` URL.

No extra server configuration or paid Vercel features are required.
